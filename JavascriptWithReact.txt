1)  The Javascript Runtime and EventLoop:
	Eventhough Javascript is a single-threaded it uses Runtime and Event Loop to do asynchronous tasks.
	🧠 Process:

	- JS executes code line by line (call stack).
	- Long-running tasks (e.g. timers, HTTP requests) go to Web APIs.
	- When done, their callbacks go to the callback queue.
	- The event loop checks if the call stack is empty — then pushes callbacks from the queue into the stack.

          📊 Diagram (simplified):
	Call Stack  <——>  Event Loop  <——>  Callback Queue
                                                          ↑
                                                           |
                                                     Web APIs

Stage 5: Parallel Asynchronous Patterns in JavaScript:
		it’s time to learn how to manage multiple async tasks at once efficiently.
	Promise Combinators (Parallel Async Patterns):-
		JavaScript provides several built-in methods for running multiple Promises together, handling results, and reacting to completion or failure in flexible ways.
		We’ll cover the four major ones:
	⚡ 1. Promise.all():-
		- Runs multiple promises in parallel and waits for all of them to finish.
		- If any one promise rejects → the entire Promise.all() rejects.

	🧠 2. Promise.allSettled():-
		- Runs multiple promises in parallel but never fails completely —
		- it waits for all to finish, and gives you their results even if some failed.

			✅ Example:               const p1 = Promise.resolve("✅ Success");
					const p2 = Promise.reject("❌ Error");
					const p3 = Promise.resolve("✅ Done");
					Promise.allSettled([p1, p2, p3]).then(results => console.log(results));

		🏁 3. Promise.race()
			- Returns the first promise that settles (either resolves or rejects).

				✅ Example:
				const p1 = new Promise(resolve => setTimeout(() => resolve("First"), 2000));
				const p2 = new Promise(resolve => setTimeout(() => resolve("Second"), 1000));
				Promise.race([p1, p2]).then(result => console.log(result));


		🥇 4. Promise.any()

			Similar to race(), but it ignores rejections —
					it returns the first successful (fulfilled) result.

					✅ Example:

						const p1 = Promise.reject("❌ Failed 1");
						const p2 = Promise.reject("❌ Failed 2");
						const p3 = Promise.resolve("✅ Success 3");

							Promise.any([p1, p2, p3])
  							.then(result => console.log(result))
  							.catch(err => console.log(err));


			🧮 Summary Table
				Method	              Resolves When      Rejects When                   		  Returns
				Promise.all()	All succeed	Any fails			Array of values
				Promise.allSettled()	All finish    	Never			Array of {status, value/reason}
				Promise.race()	First settles	First rejects (if that’s first)	Single value or error
				Promise.any()	First success	All fail			Single successful value

React — Lesson 2: useEffect, Lifecycle & Side Effects

		-->A side effect is anything your component does that affects the outside world or depends on something outside itself:
			Fetching data (HTTP)
			Subscribing to events (window resize, websockets)
			Timers (setTimeout, setInterval)
			Manually manipulating the DOM or third-party libraries


	2) useEffect basics
                                                                import React, { useState, useEffect } from "react";

			useEffect(() => {
			  // side effect code here
				});
				Runs after the component renders (after paint).
				By default, it runs after every render (mount + update)
				Return value:

				useEffect(() => {
					  // start effect
						  return () => {
						    // cleanup: runs before next effect or on unmount
							  };
							});

				3) Dependency array — controlling when effect runs
						useEffect(() => {
						  console.log("runs once on mount");
						}, []); // empty array → run once when component mounts (and cleanup on unmount)

						useEffect(() => {
						  console.log("runs when `value` changes");
							}, [value]); // runs when `value` changes

						Rules:

							[] → mount only.
							[a, b] → run whenever a or b change.
							Omit dependencies → runs after every render (usually not desired).
							Always include variables you use inside the effect (or intentionally exclude with caution).
				4) Cleanup function and unmounting
				Use the cleanup to remove listeners, cancel timers, or unsubscribe:

					useEffect(() => {
  							const onResize = () => console.log(window.innerWidth);
 							 window.addEventListener("resize", onResize);
 							 return () => window.removeEventListener("resize", onResize);
								}, []);
						Cleanup runs before the next effect (on dependency change) and on unmount

	🧠 What is useRef in React?

			---> useRef is a React Hook that lets you store a value or DOM element that persists between renders, without causing re-renders.
				🧩 Syntax
					const refName = useRef(initialValue);
					refName.current → holds the current value
					Updating refName.current does not trigger a re-render



			⚙️1️⃣ Use Case:      - Accessing DOM Elements (like document.querySelector)

					In React, instead of directly using DOM selectors, we use refs.

						Example:	import React, { useRef } from "react";

								function InputFocus() {
								  const inputRef = useRef(null);
								 function handleClick() {
   								 inputRef.current.focus(); // Focus the input field
 									 }

 									 return (
   										 <div>
    										  <input ref={inputRef} placeholder="Type something..." />
     										 <button onClick={handleClick}>Focus Input</button>
   										 </div>
 										 );
											}

          				- We also use useRef for preventing rerender .

											}

___src/Timer.js__

import React, { useEffect } from "react";

function Timer() {
  useEffect(() => {
    // Effect: start the interval
    const interval = setInterval(() => {
      console.log("Tick");
    }, 1000);

    // Cleanup function: runs when the component unmounts
    return () => {
      clearInterval(interval);
      console.log("Cleanup done!");
    };
  }, []); // empty dependency array -> run once on mount

  return (
    <div style={{ marginTop: 16 }}>
      <p>Timer is running. Open your browser console to see "Tick" every second.</p>
      <p>Click the button above to unmount the Timer and trigger cleanup.</p>
    </div>
  );
}

export default Timer;
